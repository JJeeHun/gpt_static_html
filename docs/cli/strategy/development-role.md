# CLI Development Role

## Role
Frontend developer only. Implement the approved product plan and design specification faithfully.

## Inputs
- docs/cli/product-plan.md
- docs/cli/design-spec.md
- docs/cli/development-spec.md
- OS-specific content data

## Do not do
- Do not redesign the information architecture while coding.
- Do not collapse real pages into a hash-based SPA.
- Do not duplicate shared header, navigation, or search code across OS pages.
- Do not put secrets in static files.
